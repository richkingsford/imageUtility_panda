# 3-Scene Chemistry Video Images

Use `50-three-scene-video-outlines.md` as the source for image prompts.

Generation plan:

- 50 outlines total.
- 3 scene images per outline.
- 150 images total.
- Generate in batches of 5 outlines.
- Each batch produces 15 images.

Local image output should go in:

`3-scene-chemistry-videos/generated-images/`

That folder is intentionally ignored by Git so generated images never get committed to GitHub.

- `batch-01-outlines-01-05`
