# 50 Three-Scene Chemistry Video Outlines

Source list: `data/concepts-complete.json`, first 50 concepts.

Each outline has three images plus chemistry-expert dialogue. The scenes are designed to be visually different from each other: one everyday situation, one career/workplace application, and one public teaching, design, field, or simulation moment. The science stays at a middle-school level with a light career connection.

## Image Generation Profile Rules

Use each scene image line as a literal image prompt. Do not randomize inside the image generator. Every scene line has fixed fields: Style, Character, Setting, Action, Composition, and Constraints. Avoid repetitive lab-table closeups. Do not use microscope scenes. Do not make the person simply stare at, hold, or inspect the object. The selected chemistry object must remain foreground center, but the scene must show a different useful action in a different real-world context.

Fixed character distribution across the 150 scene images: 98 white characters and 52 non-white characters, which is 65.3% white. Non-white profiles are split across Black, Latino/Latina, East Asian, South Asian, Middle Eastern, mixed-race, Indigenous, and Pacific Islander characters. Scene 1 always uses exactly one 18-year-old adult, Scene 2 always uses exactly one 28-year-old adult, and Scene 3 always uses exactly one 40-year-old adult.
