# 50 Three-Scene Chemistry Video Outlines

Source list: `data/concepts-complete.json`, first 50 concepts.

Each outline has three images plus chemistry-expert dialogue. Scene 1 features 1-2 18-year-olds. Scene 2 features 1-2 28-year-olds. Scene 3 features 40-year-olds. Every image centers the selected object, with attractive model-like people actively using, testing, repairing, arranging, or transforming the object instead of passively posing.

## Image Generation Profile Rules

Use each scene image line as a literal image prompt. Do not randomize inside the image generator. Every scene line has fixed fields: Style, Character, Work surface, Action, Composition, and Constraints. The selected chemistry object must be foreground center, fully visible, sharply focused, and doing the teaching work. The person is present for attention, but the action must show useful work with the selected object.

Fixed character distribution across the 150 scene images: 98 white characters and 52 non-white characters, which is 65.3% white. Non-white profiles are split across Black, Latino/Latina, East Asian, South Asian, Middle Eastern, mixed-race, Indigenous, and Pacific Islander characters. Scene 1 always uses exactly one 18-year-old adult, Scene 2 always uses exactly one 28-year-old adult, and Scene 3 always uses exactly one 40-year-old adult.
